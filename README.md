# EASY BOOK 💈 — Mobile Appointments Booking

*Part of the EASY CODE collection — Apps Made Easy ✨*

**Live page:** https://mido9980.github.io/easy-book/

A mobile-first Arabic (RTL) booking page: the client picks a service, a day, a time slot, leaves name + phone — and the business owner instantly gets a WhatsApp notification with the booking. Built ready to offer to salons, barbershops, clinics, and any business that works by appointment.

## Features
- Service chips, date picker (min = today), 12 time slots, name + phone.
- Instant WhatsApp notification to the owner on every booking.
- Clients can check their own bookings by phone number.
- Fully data-driven: business name and services come from the `BookConfig` record.
- Booking statuses: new / confirmed / done / cancelled.

## Edit on your phone with SPCK
1. SPCK Editor → clone: `https://github.com/Mido9980/easy-book.git`
2. Credentials: GitHub username + Personal Access Token as password.
